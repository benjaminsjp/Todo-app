# På'n

Oppgavetavle for eget arbeid og for team. 

## Hva den gjør

Programmet lar deg opprette, redigere og samhandle med andre brukere i sanntid.

## Funksjoner

- Opprett organisasjoner og inviter medlemmer
- Sanntidsoppdateringer og tilstedeværelse indikatorer
- Kommentarer på oppgaver med svar og reaksjoner
- Kanban med drag&drop
- Kalender visning
- Kategoriser oppgaver basert på grupper og status
- Varslinger

## Stack

Next.js 16, React 19, TypeScript og Tailwind 4. Data i Neon Postgres via Drizzle. Innlogging med Neon Auth. Dra-og-slipp med dnd-kit, rik tekst med TipTap, profilbilder i Vercel Blob.
